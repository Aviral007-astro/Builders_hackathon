# RWX Blast Radius selector

The selector uses coverage from the pinned SQLGlot checkout, dialect and fixture dependencies, and AST comparison for comment-only Python edits.

It chooses among one to eight workers using the scorer's per-worker overhead. After scheduling the primary tests, it uses the remaining worker capacity for tests with related coverage. The additional simulated cost is capped at 250 milliseconds per commit, and the scheduler preserves all primary test assignments.

The runtime image reads the patch batch and test inventory. All test dependency metadata comes from the unmodified public checkout.

To regenerate the map, use the pinned SQLGlot checkout and the test inventory from the official kit. Run build_coverage.py with --checkout, --inventory, and --output. Then run build_affinity.py with the checkout, base map, and output map.

The fixture map also includes file reads observed during the pinned test suite. These readers are added after the static fixture selection and its fallbacks. To add those observations, run build_fixture_reads.py with the checkout, inventory, and output map followed by --base-map and the map generated by build_affinity.py.
